# ホワイトボード

複数人でリアルタイムに共有できる Web ブラウザ向けのホワイトボードです。PC・タブレット・スマートフォンで動きます。

- ペン(色・太さ・線種・筆圧)、消しゴム、テキスト(日本語入力対応)
- 描いた線やテキストを1つずつオブジェクトとして選択・移動・一括削除
- 元に戻す / やり直し、パン・ズーム
- URL を共有した相手とリアルタイムに同期
- PNG でダウンロード

## 必要なもの

- Node.js 22.12 以上(開発は 25.2 で確認)
- npm

## セットアップ

```bash
npm install
cp .env.example .env
```

`.env` の項目:

| 変数 | 意味 |
|---|---|
| `PORT` | サーバー(HTTP + WebSocket)のポート番号。未設定だとサーバーは起動エラーになります |
| `VITE_WS_PROXY_TARGET` | 開発時に Vite が `/ws` を転送する先。`PORT` と同じポートにします |

## 起動

### 開発モード

```bash
npm run dev
```

サーバー(`PORT`)と Vite の開発サーバーが同時に起動します。ブラウザで Vite が表示する URL(通常 `http://localhost:5173`)を開いてください。

同じ Wi-Fi のタブレットやスマートフォンからは、Vite が表示する `Network:` の URL(`http://192.168.x.x:5173` など)で開けます。

### 本番モード

```bash
npm run build
npm start
```

サーバーが `dist/` の配信と WebSocket を `PORT` の1ポートで提供します(`http://localhost:<PORT>`)。

## 使い方

### ボードの共有

- URL の `?room=xxxx` がボードの ID です。付けずに開くと新しい ID が自動で付きます。
- ツールバーの「共有」で URL を共有・コピーできます。同じ URL を開いた人と同じボードを編集できます。
- ボードの内容はサーバーのメモリにだけ保存されます。サーバーを再起動すると消えます。最後の1人が抜けてから1時間たったボードも消えます。

### ツール

| ツール | ショートカット | 操作 |
|---|---|---|
| 選択 | V | タップで選択、Shift+クリックで追加・解除、何もない所からドラッグで範囲選択、選択中をドラッグで移動、テキストをダブルクリック/ダブルタップで再編集 |
| ペン | P | ドラッグで描画。筆圧対応ペンでは強さで太さが変わります(実線のみ) |
| 消しゴム | E | なぞった線・テキストを丸ごと消します |
| テキスト | T | タップした位置に入力。既存テキストをタップすると再編集 |
| パン | H | ドラッグで表示を移動 |

### テキスト入力

- Enter は改行です。
- 確定は入力欄の外をタップ、Esc、Ctrl(⌘)+Enter のいずれかです。
- 日本語の変換中に押した Enter・Esc は変換の確定・取消だけに使われます。

### その他の操作

| 操作 | PC | タッチ |
|---|---|---|
| 元に戻す / やり直し | Ctrl(⌘)+Z / Ctrl(⌘)+Shift+Z、Ctrl+Y | ツールバーのボタン |
| 選択中を削除 | Delete / Backspace | ツールバーのボタン |
| 選択解除 | Esc | 何もない所をタップ |
| 表示の移動 | ホイール、Space+ドラッグ、中ボタンドラッグ | 2本指ドラッグ、パンツール |
| ズーム | Ctrl(⌘)+ホイール、トラックパッドのピンチ | 2本指ピンチ |

## 既知の制約

- 2人が同時に追加した線の重なり順は、人によって違って見えることがあります。再接続すると揃います。
- 描いている途中の線は、後から参加した人には見えません。確定した線だけが表示されます。
- 通信が切れている間は編集できません。パンとズームはできます。
- macOS の Safari では、トラックパッドのピンチでズームできません。Ctrl+ホイールでズームしてください。
- LAN 内の端末から `http://<IP>` で開いた場合、ブラウザの制限でクリップボードへの自動コピーができません。「共有」を押すと URL が表示されるので、手でコピーしてください。
