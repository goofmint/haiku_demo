# Haiku Demo — Realtime Whiteboard

ブラウザで使えるリアルタイム共有ホワイトボードです（PC / タブレット / スマートフォン対応）。

## 機能
- ペン（マウス・タッチ・ペン入力、ペンの筆圧で線の太さが変化）
- 色変更、太さ・線種（実線 / 破線 / 点線）変更
- 線やテキストを1つのオブジェクトとして管理：選択、複数選択（タップ＋「複数選択」、または範囲ドラッグ）、一括移動、一括削除、一括の色・太さ・線種変更
- 消しゴム（触れたオブジェクトを削除）、全消去
- テキスト入力（日本語IME対応。Ctrl/Cmd+Enter で確定、Escape でキャンセル。ダブルタップで編集）
- 同じURL（`?room=...`）を開いた人同士でリアルタイム共有、「URLをコピー」で共有
- PNG保存（全オブジェクトの範囲を白背景で書き出し）

## 起動方法

```bash
npm install
npm run build      # クライアントをビルド（dist/ に出力）
npm start          # http://localhost:3000 で起動
```

開発時は2つのターミナルで起動します。

```bash
npm run dev:server   # WebSocket / 静的ファイルサーバー (port 3000)
npm run dev:client   # Vite 開発サーバー (port 5173, /ws を 3000 へプロキシ)
```

## その他のコマンド

```bash
npm run typecheck    # 型チェック
npm test             # 単体テスト
```

## 制限事項
- ボードの内容はサーバーのメモリ上にのみ保持されます（サーバー再起動で消えます）。
- 元に戻す（Undo）は未実装です。
- 切断中に行った操作は送信されず、再接続時にサーバーの状態で上書きされます。
- 筆圧は `pointerType === 'pen'` の入力のみ反映します。
