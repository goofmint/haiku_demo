# 要件定義: ホワイトボードアプリ

## 概要
Webブラウザ上で動作する、複数ユーザーがリアルタイムに共有できるホワイトボードアプリ。

## 機能要件

### FR-1 描画（ペン）
- マウス / タッチ / ペン（スタイラス）で自由曲線を描ける
- Pointer Events を使用し、PC・タブレット・スマートフォンをサポート
- `PointerEvent.pressure` を取得し、筆圧に応じて線幅を変化させる（対応デバイスのみ。非対応時は一定幅）
- タッチ描画中はブラウザのスクロール/ズームを抑止する（`touch-action: none`）

### FR-2 色の変更
- 色パレット（プリセット）＋ カラーピッカー（`<input type="color">`）で描画色を変更できる

### FR-3 線の種類の変更
- 線の太さを変更できる（細 / 中 / 太 などのプリセット＋スライダー）
- 線のスタイルを変更できる（実線 / 破線 / 点線）

### FR-4 オブジェクト管理
- 描いた線（ストローク）およびテキストはそれぞれ独立したオブジェクトとして管理する
- 各オブジェクトは一意のIDを持つ
- 「元に戻す（Undo）」で自分が直近に追加したオブジェクトを取り消せる
- 「全消去」で全オブジェクトを削除できる
- 選択ツールで単一オブジェクト（タップ）または複数オブジェクト（矩形ドラッグ）を選択できる
- 選択したオブジェクトをドラッグで移動できる
- 選択したオブジェクトを一括削除できる

### FR-5 消しゴム
- 消しゴムツールでなぞったオブジェクト（線・テキスト）を丸ごと削除する（オブジェクト消しゴム）

### FR-6 リアルタイム共有
- WebSocket でサーバーに接続し、同じルームのユーザー間でオブジェクトの追加・移動・削除・全消去を即時同期する
- ルームはURLの `?room=xxx` で識別する。未指定なら新規ルームIDを生成してURLに反映する
- 後から参加したユーザーは現在の全オブジェクトを受信する（サーバーがルーム状態をメモリ保持）
- 接続状態（接続中/切断）と参加人数を表示する

### FR-7 PNGダウンロード
- 現在のキャンバス内容を白背景のPNGとしてダウンロードできる

### FR-8 テキスト入力
- テキストツールでキャンバス上をタップした位置にテキストを入力できる
- IME（日本語入力）に対応する。入力中は HTML の `<textarea>` を使い、確定後にキャンバス上のオブジェクトとして描画する
- テキストオブジェクトも色・選択・移動・削除の対象となる
- テキスト描画フォントは日本語を含むシステムフォント（sans-serif）を使用する

## 非機能要件
- TypeScript で実装する。`any` / `unknown` 型は使わない。`class` は使わない（関数＋オブジェクトで構成する）
- フレームワーク無し（Vanilla TS）＋ Vite でビルド。サーバーは Node.js + `ws`
- 設定値（色プリセット、線幅など）は定数としてまとめ、ハードコードを散らさない
- `npm run dev` でクライアント（Vite）とサーバー（ws）が同時に起動する
- `npm run build` → `npm start` で本番相当（サーバーが静的ファイルも配信）が動作する
- `npm run typecheck` が通る

## 対象外（今回スコープ外）
- 永続化（DB保存）。サーバー再起動でルームは消える
- 認証・ユーザー名
- 画像の貼り付け、図形ツール
- ピクセル単位の消しゴム
