# 要件定義書: リアルタイム共有ホワイトボード

## 1. 目的
Webブラウザ(PC・タブレット・スマートフォン)で動作し、複数ユーザーがリアルタイムに同じボードへ描画・編集できるホワイトボードアプリを作る。

## 2. 対象環境
- ブラウザ: Chrome / Edge / Safari(iPadOS・iOS含む) / Firefox の最新版
- 入力: マウス、タッチ(指)、ペン(Apple Pencil・Wacom・Surface Pen 等)
- 画面: 幅 360px 程度のスマートフォンから PC まで。縦横どちらでも操作可能

## 3. 機能要件

### FR-1 描画(ペン)
- ポインタのドラッグでフリーハンド線を描ける
- 1回のストローク(押下〜離す)を1つの「線オブジェクト」として管理する

### FR-2 色の変更
- プリセットカラー(8色程度)から選択できる
- カラーピッカーで任意色も選べる
- 選択中の色は以降の線とテキストに適用される

### FR-3 線の種類
- 太さを変更できる(スライダー)
- 線種を変更できる: 実線 / 破線 / 点線 / マーカー(半透明の太線)

### FR-4 筆圧感知(任意要件)
- `PointerEvent.pressure` を取得できるペン入力では、筆圧に応じて線幅が変化する
- 筆圧非対応デバイス(マウス・指)では一定幅で描く
- ツールバーで筆圧の ON/OFF を切り替えられる

### FR-5 オブジェクト選択・移動・一括削除
- 選択ツールでオブジェクト(線・テキスト)をタップ/クリックして選択できる
- 範囲(矩形)ドラッグで複数オブジェクトをまとめて選択できる
- Shift+クリックで選択を追加・解除できる(PC)
- 選択中のオブジェクトをドラッグでまとめて移動できる
- 選択中のオブジェクトを削除ボタン / Delete・Backspace キーで一括削除できる
- 全消去ボタン(確認ダイアログ付き)

### FR-6 消しゴム
- 消しゴムツールでなぞった線オブジェクトを丸ごと消す(オブジェクト消しゴム)
- テキストオブジェクトもなぞると消える

### FR-7 テキスト入力(日本語対応)
- テキストツールでボードをタップした位置にテキストを配置できる
- IME による日本語入力(変換中の未確定文字列を含む)が正しく扱える
  - 変換確定の Enter でテキスト入力が確定・終了しないこと
- 複数行入力に対応する
- 文字サイズを変更できる
- 既存テキストをダブルクリック/ダブルタップで再編集できる
- テキストも1オブジェクトとして選択・移動・削除できる

### FR-8 元に戻す/やり直し
- 自分の操作を Undo / Redo できる(Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z、ボタン)
- 他ユーザーの操作は自分の Undo 対象に含めない

### FR-9 リアルタイム共有
- ルームIDを含むURLを共有すると、同じボードに複数人が同時に参加できる
- 線の追加・移動・削除、テキストの追加・編集・削除が他の参加者へ即座に反映される
- 描画中の線もストローク完了を待たずに相手画面へ表示される
- 後から参加したユーザーにも既存の内容が表示される
- 参加人数を表示する
- 回線切断時は自動再接続し、接続状態を表示する

### FR-10 PNGダウンロード
- ボード全体の内容をPNG画像としてダウンロードできる
- 背景は白で出力する(透過にしない)

### FR-11 表示操作
- キャンバスのパン(ドラッグ移動)とズームができる
  - PC: ホイール / トラックパッド、スペース+ドラッグ
  - タッチ: 2本指ピンチ・2本指ドラッグ

## 4. 非機能要件
- NFR-1 描画遅延: ローカル描画はポインタ入力に追従し、体感で遅延がないこと
- NFR-2 同期遅延: 同一LAN内で他ユーザーへの反映が 200ms 以内を目安とする
- NFR-3 高DPI: Retina 等の高解像度ディスプレイでも線がぼやけない
- NFR-4 タッチ操作時にブラウザのスクロール・ズーム・長押しメニューが誤発動しない
- NFR-5 TypeScript で実装し、`any`/`unknown` 型と `class` を使わない
- NFR-6 lint・型チェック・自動テストが通ること

## 5. スコープ外(今回は作らない)
- ユーザー認証・アカウント管理
- ボード内容のサーバー永続化(サーバー再起動で内容は消える。メモリ保持のみ)
- 図形ツール(矩形・円・矢印)、画像貼り付け
- 他ユーザーのカーソル位置表示
- 部分消しゴム(線の一部だけを消す)

## 6. 確認したい事項
1. 技術構成: フロント Vite + TypeScript(フレームワークなし、Canvas 2D)、サーバー Node.js + WebSocket(`ws`)でよいか
2. 永続化: サーバー再起動で内容が消えてよいか(スコープ外としている)
3. 消しゴム: 線を丸ごと消す方式でよいか(部分消しはスコープ外としている)
