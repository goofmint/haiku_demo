# 手動確認手順書: ホワイトボード

自動テスト(サーバー・状態管理・当たり判定など)は通っています。この手順書は、ブラウザと実機でしか確かめられない部分を確認するためのものです。結果は各項目の `[ ]` を `[x]`(OK)または `[!]`(NG)にして、NG はメモ欄に症状を書いてください。

## 0. 準備

1. プロジェクトのディレクトリで次を実行します。
   ```bash
   npm install
   npm run dev
   ```
2. ターミナルに出る Vite の URL を控えます。
   - PC 用: `Local: http://localhost:5173/`
   - タブレット・スマホ用: `Network: http://192.168.x.x:5173/`(PC と同じ Wi-Fi に接続)
3. PC のブラウザで Local の URL を開きます。URL の末尾に `?room=xxxxxxxx` が自動で付けば OK です。

用意する端末(あるものだけで構いません):
- PC(Chrome、Safari、Firefox のうち1つ以上)
- iPad + Apple Pencil
- スマートフォン(iPhone または Android)
